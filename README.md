# ashare-quant：A 股日线回测框架

一个**贴近 A 股真实交易规则**的轻量级事件驱动回测框架，附带可复现的策略、绩效分析和防过拟合的参数样本外检验。

> 本项目仅用于量化研究与学习，不构成投资建议。回测收益不代表未来表现。

## 特性

| 模块 | 说明 |
|---|---|
| 交易规则 | 100 股一手、T+1、停牌不可交易、开盘涨停不可买/跌停不可卖（主板 10%，创业板 2020-08-24 起 20%，科创板 20%，北交所 30%），未成交订单次日自动重试 |
| 交易成本 | 佣金（含最低 5 元）；印花税与过户费按历史规则表取当时口径（印花税 2005-01-24 起 0.1%、2007-05-30 起 0.3%、2008-04-24 起 0.1%，2008-09-19 前买卖双向、之后仅卖方，2023-08-28 起 0.05%；过户费 2015-08-01 前仅沪市按每股 0.001 元、最低 1 元，之后按成交额 0.02‰，2022-04-29 起 0.01‰）；ETF 免印花税与过户费；可配置滑点；网页版另有成交容量上限（单日不超过前 20 日均成交额的一定比例，超出部分次日继续）与平方根冲击成本 |
| 无未来函数 | t 日收盘出信号 → t+1 日开盘成交；有单测验证"篡改未来数据不影响历史净值" |
| 数据 | 直接请求东方财富日线接口（与网页版同一接口，本地缓存，网络错误自动重试），可选 [akshare](https://github.com/akfamily/akshare)（`pip install akshare`），或本地 CSV、合成数据 |
| 策略 | 买入持有（基准）、双均线趋势、ETF 动量轮动（含绝对动量过滤） |
| 绩效 | 年化收益、波动率、夏普、索提诺、最大回撤及持续天数、卡玛比率、手续费、年化换手率 |
| 参数优化 | 网格搜索，按样本内指标选参，同时输出样本外表现，识别过拟合 |
| 报告 | 净值/回撤图（PNG）、指标对比（Markdown）、净值与成交明细（CSV） |

## 快速开始

```bash
pip install -r requirements.txt

# ETF 动量轮动：沪深300、中证500、创业板、黄金、国债
python -m ashare_quant backtest --strategy momentum \
    --symbols 510300,510500,159915,518880,511260 \
    --start 2015-01-01 --end 2024-12-31 \
    --param lookback=60 --param top_n=2 --param rebalance=20

# 个股双均线
python -m ashare_quant backtest --strategy dual_ma --symbols 600519 --param fast=20 --param slow=60

# 参数网格搜索：2021 年前为样本内，之后为样本外
python -m ashare_quant optimize --strategy dual_ma --symbols 600519 \
    --grid fast=5,10,20 --grid slow=30,60,120 --split 2021-01-01

# 无网络时用合成数据体验
python -m ashare_quant backtest --strategy momentum --symbols 510300,510500,159915 --source synthetic
```

报告输出在 `output/`：`summary.md`、`report.png`、`equity.csv`、`trades.csv`。

常用参数：`--cash` 初始资金、`--commission` 佣金率、`--min-commission` 最低佣金、`--slippage` 滑点、`--band` 调仓容差、`--adjust qfq|hfq|""` 复权方式、`--source eastmoney|akshare|csv|synthetic`、`--data-dir` 缓存/CSV 目录（CSV 命名为 `<代码>.csv`，需含 `date,open,high,low,close,volume` 列）。

## 网页版（手机可用）

`docs/` 是纯前端的研究工具，全部计算在浏览器本地完成，不需要服务器，手机上也能用。

**回测**
- 回测区间：起止日期与"近 1/3/5/10 年、全部"快捷设置，回测、优化、因子研究共用
- 最终留出期：设定起始日后，这一天及以后的数据对所有功能不可见；解锁需确认并记录次数，用于策略定型后的最后一次检验
- 规则组合：16 条指标规则——均线交叉、EMA 交叉、价格与均线、均线斜率、MACD、DMI/ADX 趋势强度、CCI 突破、RSI、威廉 %R、KDJ、布林带回归、唐奇安通道突破、动量 ROC、放量上涨、OBV 能量潮、波动率过滤；每条规则可设为"入场和出场 / 只用于入场 / 只用于出场"，入场"全部满足/任一满足"，出场"任一触发/全部触发"
- 风控与持仓（按实际成交闭环：成本价取实际成交价含费用，持有天数与冷却期从实际成交日算起，涨停没买进不算持仓）：止损、止盈、ATR 移动止损、最多持有几只（信号多于仓位时按近 20 日涨幅择优）、最短持有天数、最长持有天数（时间止损）、平仓后冷却天数；仓位可按 1/N 固定、持仓等分或波动率倒数分配
- 多因子选股：多个因子在标的之间排名打分、按权重合成，每期买入前 N 只，可加大盘趋势过滤；仓位可选"组合优化"："持有几只"是持仓数量上限，候选为综合分最高的 N 只加仍排在前 2N 的现有持仓（优化后多于 N 只时保留权重最大的 N 只再优化），Grinold 预期收益 α = IC × σ × z，协方差用过去 250 日收益的 Ledoit–Wolf 收缩估计（向常相关），在单票上限（硬约束：放不满时剩余为现金，不放宽上限）、换手惩罚（单边成本，以**实际持仓**而不是上一次目标为起点）下做均值-方差优化（FISTA 近端梯度，换手与上限的近端算子精确求解）；大盘趋势过滤用沪深300 官方指数，没有时用"前一交易日在池内的标的"日收益等权的链式指数（未来才纳入的股票不影响纳入前的决策）；因子库含动量、反转、均线偏离、RSI、MACD、布林 %B、KDJ、波动率、ATR、量比，以及距 250 日新高、20 日最大单日涨幅（彩票效应）、Amihud 非流动性（|收益| / 真实成交额，成交额用不复权价 × 成交量）；个股池另有盈利收益率 E/P（TTM）、账面市值比 B/P、ROE（TTM）、净利润与营收同比增速、流通市值
- 另有 ETF 动量轮动与买入持有
- 评价：收益/风险指标；相对等权基准的 α、β、信息比率、跟踪误差；个股池另有相对沪深300 官方指数（价格指数）的同组指标；暴露归因：对股票池内的因子模拟组合回归（市场、规模、价值、动量、低波动、质量、非流动性，数据支持哪些就用哪些），个股池另给出加入行业因子的模型，Newey–West t 值，给出剔除暴露后的 α，并列出当前持仓相对成分等权的行业偏离；按笔统计的胜率、盈亏比、利润因子、平均持有天数；月度收益表
- 最新信号：每只标的当前持仓、各规则的多空状态、下一交易日开盘要做的操作；可"冻结今日信号"作为影子账户：目标仓位连同策略、数据指纹与执行假设写入研究账本，之后更新行情时交给同一个回测引擎成交（次日开盘、真实价格、整手、涨跌停与停牌、费用、滑点、容量；每次冻结按那次保存的执行假设），每段结算的净值、成交与期末持仓写入账本、之后不再重算（行情事后修订不会改写过去的记录）；只能冻结最新交易日的信号，积累真正的样本外记录
- 风险分解：当前持仓与基准成分的 Ledoit–Wolf 协方差，给出组合波动、相对成分等权的跟踪误差及其行业、个股来源
- 容量与成本压力：资金规模 100 万 ~ 10 亿、成本 1 ~ 3 倍下重跑，看净夏普何时明显下滑

**个股池（沪深300 历史成分，时点股票池）**
- 成分数据 `docs/data/hs300_members.json`：`tools/build_hs300.py` 从中证指数公司 2005 年以来的历次调整公告重建（67 次调整、941 只曾为成分的股票，含大市值新股快速进入与吸收合并退市），逐步校验每一步恰好 300 只、调出的都在指数内，推演结果与中证官网当前成分表完全一致；2005–2010 年的剔除日期与新浪历史成分独立核对吻合
- 每只股票只在它是成分股的时段内可以买入（由回测引擎强制：决策日不是成分股的买单一律拒绝，与策略写法无关），被剔出后卖出；基准为当期成分等权；在成分期内退市的持仓按最后价格 × 回收比例注销（交易设置里可调，默认 0%）
- 严格模式（默认开）：任一交易日应在池内的成分股里有行情的不足 99.5% 时拒绝回测，并列出缺的股票——缺数据的多是后来退市、被剔除的股票，静默删除会造成幸存者偏差
- 行情、财务数据、股本变动历史与分红送配明细在浏览器里从东方财富获取（每只股票只取成分期前后的区间），存进本机 IndexedDB，可暂停、下次接着取；财务数据用"主要指标"接口（含已退市公司），公告日的下一个交易日起才可用，滚动 12 个月值只用当时已公告的报告计算
- 追溯调整：数据源会在次年用追溯调整后的数值覆盖上年数据（例如平安银行 2012 年每股收益原始披露 2.62 元，库里是按 2013 年送股调整后的 1.64 元）。因此 E/P = 滚动归母净利润 / (不复权价 × 当时总股本)、ROE = 滚动归母净利润 / 归母净资产，不用每股收益；另可选"财报可用日 = 最后更新日"的保守口径做稳健性检验
- 股本是双时态数据：每条记录有生效日（变动日 / 报告期末）和公告日，只有公告之后才可用；可用之后按生效日还原当时的状态。报告期归母净资产 = 每股净资产（数据源为报告期口径，未被之后的送转追溯调整）× 报告期末总股本；B/P = 报告期归母净资产 / 当前总市值（不用"每股净资产 / 当前股价"：报告期后送转会把它放大）
- 规模因子：流通市值 = 不复权价 × 当时流通 A 股（来自股本变动历史）；缺股本数据时用换手率反推
- 行业：东方财富一级行业（`docs/data/hs300_industry.json`，`tools/build_industry.py` 生成）。这是**当前分类，不是时点数据**，因此只用于事后归因（暴露回归的行业因子、持仓行业偏离）；行业中性化与行业约束会被拒绝（`meta.industryPIT === true` 才放行）。信号层可用的是市值中性（对数流通市值回归取残差，市值是时点数据）
- 成交用真实价格：信号用复权价，成交、估值、涨跌停、费用、成交额用不复权价；公司行为用分红送配明细（除权除息日、每股派现、每股送转）：送转增加股数（零碎股按除权参考价折现），派现计入现金。仅凭复权因子无法区分派现与送转（10% 派现与 10 送 1 的因子完全相同），所以没有明细对应的复权跳变（没有明细数据、配股等）一律按"价值不变、差额计现金"处理，不凭空增加股数，并在结果页报告次数；明细与复权因子对不上的也会报告
- 上市日期（同一文件）：注册制新股上市前 5 个交易日（科创板、2020-08-24 起的创业板、2023-04-10 起的主板）、北交所上市首日不设涨跌幅
- 起始年份可选 2018 / 2015 / 2010（约 560 / 670 / 800 只）；标的多时页面只列持仓与待买入的信号，序列特征只算前 40 只

**参数优化**（后台线程运行，页面不卡）
- 网格或随机搜索，规则参数、风控与持仓参数、因子权重与选股参数都可以纳入；目标可选夏普、索提诺、卡玛、年化收益，可设训练集最少成交笔数
- 训练 / 验证 / 测试三段划分：训练集给参数排序，验证集在训练排名前 10%（至少 5 组）中选出最终参数，测试集锁定，点"揭晓"后才显示选定参数的测试结果，并记录同一测试集被查看的次数
- 滚动前推（walk-forward）：只在训练+验证段内进行，每个窗口只用之前的数据选参，由同一个账户连续交易（换参数时的调仓按真实规则成交并计费用），给出费用、换手与按笔统计
- 通缩夏普比率（Bailey & López de Prado）：试验次数取研究账本在同一份数据上累计记录的回测配置数与优化组合数（全部设备合计），检验最终选定的参数（其训练集夏普对比 N 次试验的期望最大值，比检验第一名更保守）；优化目标不是夏普时标明只是夏普尺度的辅助诊断；在别处做过的尝试无法计入，仍偏乐观
- 回测过拟合概率 PBO（Bailey 等的组合对称交叉验证 CSCV）：训练+验证段切成 12 块，枚举 924 种"一半样本内、一半样本外"，按与优化目标相同的标准（夏普、索提诺、年化收益可由分块统计精确拼合；卡玛依赖整条路径的回撤，用年化收益近似并标明）选出样本内冠军，统计它在样本外落到后一半的概率，另给样本外亏损概率与回归斜率
- Hansen SPA 检验：全部参数组合相对基准的日超额收益，平稳自助法 1000 次并给出 p 值的蒙特卡洛误差；回答"试了这么多组之后，最好的那组是否真的优于基准"。PBO 每块平均不足 60 个交易日时提示样本太短
- 研究账本（`docs/ledger.js`）：只追加、带 SHA-256 哈希链；每个不同的实验清单（数据指纹覆盖每只标的每个字段的每个值与全部元数据；清单含策略配置、全部执行假设、区间、留出期、数据口径与代码版本，只改滑点也算一次新试验）、每次优化（同一套实验清单，加上搜索空间、目标、划分与前推设置）、因子研究查看过的每个视图（分析类型 × 因子 × 预测周期 × 中性化，计入试验次数）、每次查看测试集、每次解锁最终留出期、每次冻结信号与影子账户结算都会记入；代码版本是页面实际加载的全部脚本的 SHA-256，不是手工维护的字符串；链内的改动与中间删除校验时会暴露，末尾删除要和保存在链外的锚点（每条链最后一条的序号与哈希）对比才能发现；可导出备份、在其他设备导入合并（每台设备一条链）
- 参数热力图：训练集或验证集，区分稳定的参数区域和孤立的过拟合尖峰

**时序与因子**
- 收益序列：偏度、超额峰度、自相关（含绝对收益的波动聚集）、Lo–MacKinlay 方差比检验
- 因子相关性矩阵（截面秩相关按日期平均），标出 |ρ| > 0.7 的重复因子
- 信号衰减：截面 IC 随预测周期（1 / 5 / 10 / 20 / 60 日）的变化、逐年截面 IC、因子秩自相关
- 因子的时序 IC 与截面 IC：非重叠抽样，95% 置信区间用按日期的块自助法（所有标的同时重抽，重复或高度相关的标的不会虚增显著性），前后半段对比，并提示多重检验下的偶然显著数
- 可交易的分组组合（≥10 只分 5 组，6~9 只分 3 组）：每期按因子排序，每组都交给回测引擎实际成交（真实价格、整手、涨跌停、停牌、费用、滑点、容量与回测设置一致），给出各组与多空的年化、夏普、年化成本、换手和前后半段表现
- IC 与衰减用的未来收益只在"买入日与卖出日都能成交"时计入（停牌、开盘涨停买不进、开盘跌停卖不出的样本剔除），不用前值"成交"

**审计回归测试**：`tests/web/audit.test.js`、`audit2.test.js` 把两轮外部源码审计的问题写成对抗性用例（第二轮：10% 派现被当成送股、Amihud 用复权价、股本生效日与公告日混淆、组合优化持仓数超过 N、账本末尾删除、优化与因子研究未完整记账、PBO / DSR 的检验对象、影子账户分段与冻结结算）；第一轮 12 项（篡改未来成分纳入前的价格、非时点行业、停牌日成交、送转分红、引擎层股票池、单票上限、指纹与清单、实际持仓起点、影子账户、科创板手数与 ETF 涨跌幅、部分成交补单、SPA/PBO 精度）。

**防未来函数的系统测试**：`tests/web/lookahead.test.js` 把某天之后的全部行情、财务、股本、成分数据随机篡改，要求注册表里的每个因子、每条规则、风格因子，以及每种策略（含组合优化、成交容量与冲击）在该天及以前的值、净值与成交完全不变；新增的因子或规则自动纳入检验。

指标口径与通达信一致（EMA 首值为种子，RSI/KDJ 用 SMA(X,N,1) 平滑，MACD 柱 = 2×(DIF−DEA)）。测试覆盖：`tests/test_web_indicators.py` 逐点对照 pandas 独立实现；`tests/test_web_parity.py` 比对网页版与 Python 版引擎的逐日净值；`tests/web/research.test.js` 覆盖策略状态机、优化、前推与统计函数。

## 编写自己的策略

策略只需把收盘价矩阵映射为目标权重矩阵：

```python
import numpy as np
import pandas as pd
from ashare_quant import Backtester, Strategy, load_universe, summarize

class LowVol(Strategy):
    """每月持有过去 60 日波动率最低的 2 个标的。"""
    name = "low_vol"

    def generate(self, close: pd.DataFrame) -> pd.DataFrame:
        vol = close.pct_change().rolling(60).std()
        out = pd.DataFrame(np.nan, index=close.index, columns=close.columns)
        for i in range(60, len(close), 20):
            pick = vol.iloc[i].nsmallest(2).index
            out.iloc[i] = 0.0
            out.iloc[i, out.columns.get_indexer(pick)] = 0.5
        return out

data = load_universe(["510300", "510500", "518880", "511260"], "2016-01-01", "2024-12-31")
result = Backtester(data).run(LowVol())
print(summarize(result))
```

约定：某行只要有非 NaN 值即为当日收盘后的完整目标仓位（NaN 视为 0），全 NaN 行表示不调仓；权重非负且和不超过 1。只使用 `rolling`、`shift` 等向后看的计算。

## 已知局限

- 仅日线、仅做多，按开盘价成交，不模拟盘中撮合；成交量约束是按前 20 日均额的参与率上限
- 真实价格只在有不复权价时可用（个股池、在线获取）；上传的 CSV 与示例数据只有一套价格，成交价就是给定价格
- 未处理 ST 股 5% 涨跌幅；派现按税前金额计（红利税因持有期与账户类型而异，未扣）；配股不在分红送配明细里，按"价值不变折现"近似（未模拟缴款认购）；复权价与不复权价各自舍入到分，低于舍入容差（约 0.01/股价 × 2，低价股约 0.3~0.7%）的小额分红会被忽略
- 创业板 ETF 的 20% 涨跌幅名单只含已核实的 159915、159949（其他可用 `meta.priceLimit` 覆盖）
- 个股池只有沪深300；已退市公司能否取到行情取决于东方财富，取不到的会在页面上列为缺失
- 财务数据没有真正的"原始披露库"：净利润、每股净资产按数据源记录（抽查与原始披露一致），营收与利润同比增速可能用了追溯调整后的上年数；保守口径（最后更新日）可以检验结论是否依赖这一点
- 沪深300 官方指数为价格指数，不含分红（全收益约高 2%/年）
- 行业分类不是时点数据：信号层不能用行业中性化 / 行业约束，要用需要自备时点行业库
- 冲击成本模型是经验公式（平方根律），系数需要自己按实盘校准
- 研究账本存在本机浏览器，不是服务器上的不可篡改记录：哈希链能发现链内的改动与中间删除，末尾删除只能和保存在链外的锚点对比发现；清空浏览器数据会丢掉整条链（请定期导出备份）；在账本之外做的尝试无法计入
- 风险模型是个股层面的收缩协方差，还不是结构化的多因子风险模型（B·Σ_F·Bᵀ + D）；组合优化只做多、满仓
- 没有真正的历史版本（as-reported）财务库：数据源只提供最新值，只能靠"最后更新日"口径做稳健性检验；本工具从现在起记录数据指纹，但无法回补过去的版本
- 计算全部在浏览器中进行，适合几百只股票、几十个因子的规模；更大规模的研究（全 A 股、机器学习）需要 Python 后端
- 自选股票列表（非个股池）是固定名单，用当下的股票回测历史会有幸存者偏差
- 理想化预览（`generate`）按信号当天收盘价假设成交，只用于检查信号逻辑；回测一律按实际成交闭环计算
